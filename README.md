# Chat App 💬

A simple real-time chat application built with **React**, **Firebase**, and **Vite**.

## 🚀 Features
- 🔥 Firebase Authentication (Register & Login)
- 💬 Real-time messaging
- 🧑‍🤝‍🧑 User search and chat creation
- 🎨 Clean, modern React UI
- ⚡ Built with Vite for fast development

## 🛠️ Tech Stack
- **Frontend:** React + Vite
- **Backend:** Firebase (Auth & Firestore)
- **Styling:** Tailwind CSS (if used)
- **Icons:** React Icons
